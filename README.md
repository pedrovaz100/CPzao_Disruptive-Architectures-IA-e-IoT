🐾 Alimentador Automático para Pets com Arduino
📌 Descrição
Este projeto consiste em um alimentador automático para pets utilizando o Arduino Uno, capaz de liberar ração em horários programados, além de permitir acionamento manual por botão.

O sistema também conta com:

Display LCD para exibição de status
Alarme sonoro (buzzer)
Controle de abertura via servo motor
Relógio em tempo real (RTC)
⚙️ Funcionalidades
✅ Liberação automática de ração em horário definido ✅ Botão para liberação manual ✅ Display LCD mostrando status do sistema ✅ Alarme sonoro ao liberar ração ✅ Controle de abertura/fechamento do compartimento

🧩 Componentes Utilizados
Arduino Uno
Servo Motor (SG90)
Módulo RTC (DS3231 ou DS1307)
Display LCD 16x2 com I2C
Botão (Push Button)
Buzzer
Protoboard
Jumpers
Fonte de alimentação (USB ou externa)
🔊 Funcionamento do Sistema
O alimentador funciona de duas formas:

Automático:

Em um horário programado, o sistema abre o compartimento de ração
A comida é liberada no prato
Um alerta sonoro é emitido
O compartimento é fechado automaticamente
Manual:

Ao pressionar o botão, o sistema libera ração imediatamente
📟 Mensagens no Display
O display LCD informa o status do sistema, como:

"Aguardando"
"Liberando..."
"Ração liberada"
"Fechado"
🚀 Possíveis Melhorias
Adicionar múltiplos horários de alimentação
Controle via Bluetooth ou Wi-Fi
Sensor de nível de ração
Aplicativo para monitoramento
Estrutura física personalizada (impressão 3D)
🐶 Aplicação
Ideal para:

Donos que passam muito tempo fora de casa
Controle de dieta do pet
Automação residencial
